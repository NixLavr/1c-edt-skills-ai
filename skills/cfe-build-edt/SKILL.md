# /cfe-build-edt — сборка расширения CFE из EDT

Собирает файл расширения `.cfe` из EDT-проекта основной конфигурации и EDT-проекта расширения.

## Когда использовать

Используй этот skill, если:
- в проекте есть EDT-конфигурация (`V8ConfigurationNature`)
- рядом есть EDT-расширение (`V8ExtensionNature`)
- пользователю нужен именно бинарный файл `.cfe`

Не используй для внешних обработок `.epf`/`.erf` — для них есть отдельные skills.

## Что делает

1. Экспортирует EDT-проект основной конфигурации в XML конфигуратора через `1cedtcli`
2. Экспортирует EDT-проект расширения в XML конфигуратора через `1cedtcli`
3. Создаёт временную файловую ИБ через `1cv8.exe CREATEINFOBASE`
4. Загружает в ИБ XML основной конфигурации
5. Загружает в ИБ XML расширения через `-Extension`
6. Выгружает готовый `.cfe` через `/DumpCfg -Extension`

## Команда

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts\cfe-build-edt.ps1
```

## Параметры скрипта

| Параметр | Обязательный | Описание |
|----------|:------------:|----------|
| `-BaseProjectPath <путь>` | нет | Путь к EDT-проекту основной конфигурации |
| `-ExtensionProjectPath <путь>` | нет | Путь к EDT-проекту расширения |
| `-OutputFile <путь>` | нет | Путь к итоговому `.cfe` |
| `-BuildRoot <путь>` | нет | Каталог временных файлов сборки |
| `-ExtensionName <имя>` | нет | Имя расширения в конфигураторе. Если не задано — читается из экспортированного `Configuration.xml` |
| `-V8Path <путь>` | нет | Полный путь к `1cv8.exe` |
| `-EdtCliPath <путь>` | нет | Полный путь к `1cedtcli.exe` |
| `-JavaBinPath <путь>` | нет | Путь к каталогу `bin` JDK для EDT CLI |
| `-KeepTemp` | нет | Не удалять временные каталоги после сборки |

## Значения по умолчанию

Если параметры не заданы, скрипт предполагает:
- основная конфигурация: `Информационная_база`
- расширение: `Информационная_база.Расширение`
- результат: `build\Расширение.cfe`
- временные файлы: `build\cfe-build`

Пути к `1cedtcli`, JDK и `1cv8.exe` определяются автоматически по стандартным каталогам установки 1С.

## Важные замечания

- `1cedtcli` требует Java. Скрипт временно добавляет JDK EDT в `PATH`.
- В некоторых средах запуск `1cv8 DESIGNER` и `1cedtcli` может требовать повышенных прав или доступа вне sandbox.
- Если имя расширения отличается от имени проекта, приоритет у `-ExtensionName`. Иначе имя читается из экспортированного XML расширения.

## Пример

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts\cfe-build-edt.ps1 `
  -BaseProjectPath "C:\Users\Nix Lavr\Documents\1C\EDT\Бух\Информационная_база" `
  -ExtensionProjectPath "C:\Users\Nix Lavr\Documents\1C\EDT\Бух\Информационная_база.Расширение" `
  -OutputFile "C:\Users\Nix Lavr\Documents\1C\EDT\Бух\build\Расширение.cfe"
```

## После выполнения

1. Проверь, что итоговый `.cfe` существует
2. Покажи путь к результату
3. Если были ошибки, сначала прочитай логи из `BuildRoot\logs`
